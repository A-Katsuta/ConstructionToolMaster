# ゲームデータの追加・編集ガイド

このドキュメントでは、ゲームに登場する工具の種類を増やしたり、画像を追加したりする方法について説明します。

## 1. 編集するファイル
**ファイルパス:** `src/data/tools.ts`

このファイルには、ゲームで使用される全ての工具データがリスト形式（配列）で記述されています。

## 2. データの追加方法
`tools` という配列の中に、新しい `{ ... }` のブロック（オブジェクト）を追加します。

### 記述例
```typescript
    {
        id: '6', // 他の工具と被らないユニークな番号または文字列
        formalName: '新しい工具の名前',
        colloquialNames: ['通称1', '通称2'],
        description: '工具の説明文をここに書きます。',
        imageUrl: '/images/new-tool.jpg', // 画像のパス（後述）
        category: 'hand', // カテゴリを選択 (power, hand, safety, measurement, other)
        difficulty: 1, // 難易度 (1, 2, 3)
    },
```

### 各項目の説明
*   **id**: 工具を識別するためのIDです。他の工具と重複しないようにしてください。
*   **formalName**: 工具の正式名称です。
*   **colloquialNames**: 現場での通称やあだ名です。複数ある場合は `['名前1', '名前2']` のようにカンマで区切って記述します。
*   **description**: 学習モードなどで表示される解説文です。
*   **imageUrl**: 画像ファイルの場所を指定します。
*   **category**: 工具の種類です。以下のいずれかを指定してください。
    *   `'power'` (電動工具)
    *   `'hand'` (手工具)
    *   `'safety'` (安全具)
    *   `'measurement'` (測定器具)
    *   `'other'` (その他)
*   **difficulty**: 問題の難易度です（現在は表示上の目安ですが、将来的な機能拡張に使えます）。

## 3. 画像の追加方法
画像ファイルを追加する最も簡単な方法は、`public` フォルダを使用することです。

1.  プロジェクトの `public` フォルダを開きます。
    *   パス: `ConstructionToolMaster/public`
2.  整理のために、中に `images` というフォルダを作成することをお勧めします。
3.  用意した画像ファイル（例: `hammer.jpg`）を `images` フォルダの中にコピーします。
4.  `tools.ts` の `imageUrl` には、以下のように `/` から始まるパスを記述します。
    *   `imageUrl: '/images/hammer.jpg'`

### 注意点
*   `public` フォルダに置いたファイルは、Webサーバーのルート（一番上の階層）から直接アクセスできる状態になります。
*   画像サイズは大きすぎると読み込みが遅くなるため、適度なサイズ（例: 横幅 600px〜800px程度）に調整することをお勧めします。
