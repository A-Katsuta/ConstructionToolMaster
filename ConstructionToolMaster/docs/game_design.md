# ゲームデザイン書 (GDD) - 建設工具マスター

## 1. ゲームコンセプト
**タイトル:** 建設工具マスター (仮)
**ジャンル:** 教育 / パズル
**プラットフォーム:** Web (モバイルファースト)
**ターゲット:** 建設作業員、学生、DIY愛好家

## 2. ゲームシステム

### 2.1 コアループ
1.  **出題:** 建設工具の画像が表示される。
2.  **回答:** プレイヤーは選択肢から正解を選ぶ、または名称を入力する（難易度による）。
3.  **フィードバック:** 即座に正誤判定。正解の場合、正式名称と「現場での通称（あだ名）」の両方を表示して解説する。
4.  **進行:** 1セット10問などで区切り、ラウンドを完了する。

### 2.2 モード
*   **学習モード (Learning Mode):** 時間制限なし。暗記に集中するモード。各問題の後に詳細情報を表示。
*   **スコアアタック (Score Attack):** 制限時間あり（例: 60秒）。時間内に何問正解できるかを競う。連続正解（コンボ）でボーナス。

## 3. ゲームフロー
1.  **タイトル画面:** スタートボタン、設定、ハイスコア。
2.  **モード選択:** 学習モード または スコアアタック を選択。
3.  **ゲームプレイ画面:**
    *   タイマー (スコアアタック時)
    *   工具画像 (中央)
    *   回答ボタン
    *   スコア / 進捗表示
4.  **リザルト画面:**
    *   最終スコア / 正答率
    *   出題された工具の一覧（復習用）
    *   「リトライ」または「タイトルへ戻る」ボタン

## 4. データ構造 (概念)
*   **工具データ:**
    *   画像URL
    *   正式名称 (例: インパクトドライバ)
    *   通称 (例: ガチャ、インパクト)
    *   カテゴリ (例: 電動工具、手工具)

## 5. ビジュアルスタイル
*   **テーマ:** インダストリアル、クリーン、ハイコントラスト（安全第一の黄色/黒をアクセントに）。
*   **UI:** モバイル操作に適した大きめのボタン。
