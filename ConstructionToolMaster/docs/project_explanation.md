# プロジェクト解説書

このドキュメントでは、今回作成した「建設工具マスター」のファイル構成、できること、およびIT初心者向けのQ&Aについて詳しく解説します。

## 1. ファイル構成と中身について

このプロジェクトは、現代的なWeb開発の標準的な構成（Vite + React + TypeScript）で作られています。

### 📁 フォルダ構成

*   **`ConstructionToolMaster/`**: プロジェクトのルートフォルダです。
    *   **`src/` (Source)**: **最も重要なフォルダです。** ゲームのプログラム本体（ソースコード）がここに入っています。
        *   `App.tsx`: アプリ全体のまとめ役となるファイルです。画面の切り替えなどを管理しています。
        *   `main.tsx`: アプリをブラウザに表示（レンダリング）するための入り口となるファイルです。
        *   `index.css`: アプリ全体のデザイン（スタイル）を決めるファイルです。
        *   **`components/`**: 「ボタン」や「カード」など、画面の部品（コンポーネント）が入っています。
        *   **`pages/`**: 「タイトル画面」「ゲーム画面」「結果画面」など、各ページのまとまりが入っています。
        *   **`hooks/`**: ゲームのルール（点数計算、タイマーなど）を管理するロジックが入っています。
        *   **`data/`**: クイズの問題データ（工具の名前や画像URL）が入っています。ここを編集すると問題を増やせます。
        *   **`types/`**: プログラム内で扱うデータの「型（ルール）」を定義しています。
    *   **`public/`**: 画像などの静的なファイルを置く場所です。ここにあるファイルはそのまま公開されます。
    *   **`docs/`**: 設計書や要件定義書などのドキュメントが入っています。
    *   **`project_docs/`**: プロジェクト管理用のタスクリストなどが入っています。
    *   **`dist/` (Distribution)**: `npm run build` コマンドを実行した後に作られる、**本番公開用**のファイル一式が入る場所です。
    *   **`node_modules/`**: プロジェクトに必要なライブラリ（Reactなど）が大量に入っています。**手動でいじる必要はありません。**

### 📄 設定ファイル

*   `package.json`: プロジェクトの「名札」兼「設計図」です。必要なライブラリや、実行コマンド（`npm run dev`など）が書かれています。
*   `vite.config.ts`: 開発ツール（Vite）の設定ファイルです。
*   `tailwind.config.js` / `postcss.config.js`: デザインツール（Tailwind CSS）の設定ファイルです。
*   `tsconfig.json`: プログラミング言語（TypeScript）の設定ファイルです。

## 2. このファイル一式を使ってできること

### 🎮 ゲームを遊ぶ・テストする
自分のパソコン上でゲームを動かして遊ぶことができます。
*   コマンド: `npm run dev`

### ✏️ クイズの問題を増やす・変える
`src/data/tools.ts` というファイルを書き換えることで、簡単に問題をカスタマイズできます。
*   例: 新しい工具を追加したり、説明文を変えたり、画像を差し替えたりできます。

### 🎨 デザインや動きを変える
プログラム（`src`フォルダの中身）を編集して、自分好みのゲームに改造できます。
*   例: 制限時間を60秒から30秒に変える（`src/hooks/useGame.ts`を編集）。
*   例: 背景色を変える（`src/index.css`や各コンポーネントを編集）。

### 🌍 インターネットに公開する
「ビルド」という作業を行うことで、インターネット上のサーバー（VercelやNetlifyなど）にアップロードできる形式に変換できます。
*   コマンド: `npm run build`
*   生成された `dist` フォルダの中身をサーバーにアップロードすれば、世界中の人が遊べるようになります。

## 3. IT初心者向け Q&A

このファイル一式を見たときに出てきそうな疑問に答えます。

### Q1. `npm` って何ですか？
**A. アプリ開発のための「道具箱」兼「管理マネージャー」です。**
Node Package Managerの略です。このゲームを作るのに必要な部品（Reactなど）をインターネットから取ってきたり、ゲームを起動させたりする命令を出すために使います。

### Q2. 黒い画面（ターミナル）を使わないとダメですか？
**A. 基本的には必要です。**
プログラミングの世界では、マウスでポチポチするよりも、文字で命令（コマンド）を打つ方が正確で早いため、この方式が一般的です。慣れると「魔法の呪文」みたいで便利ですよ。

### Q3. 「ビルド (Build)」って何をしているんですか？
**A. 「翻訳」と「圧縮」をしています。**
私たちが書いたプログラム（TypeScriptなど）は、実はそのままではブラウザが理解しにくい形をしています。それをブラウザが高速に読み込める形式（普通のJavaScriptなど）に変換し、ファイルサイズをギュッと小さくする作業を「ビルド」と呼びます。

### Q4. `node_modules` フォルダがすごく重いんですが、消してもいいですか？
**A. 消しても大丈夫ですが、ゲームが動かなくなります。**
ここにはゲームを動かすための部品が何千個も入っています。もし消してしまったり、場所を移動したい場合は、もう一度 `npm install` というコマンドを打てば、`package.json` の内容を元に自動で復元してくれます。

### Q5. 自分のスマホで遊ぶにはどうすればいいですか？
**A. インターネット上に「デプロイ（公開）」する必要があります。**
今の状態（`npm run dev`）は、あなたのパソコンの中でしか動いていません。Vercel（バーセル）やNetlify（ネットリファイ）といった無料のホスティングサービスを使うと、簡単にインターネット上に公開でき、スマホからURLにアクセスして遊べるようになります。

### Q6. コンポーネント (Component) って何ですか？
**A. 「レゴブロック」のような部品のことです。**
このアプリでは、「ボタン」や「カード」などを一つの部品（コンポーネント）として作っています。これらを組み合わせることで画面を作っています。部品化しておくと、同じボタンを何度も使い回せるので便利です。
