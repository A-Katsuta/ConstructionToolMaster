# 建設工具マスター - 要件定義書

## 1. プロジェクト概要
建設現場で使用される工具の名称（正式名称および現場での通称）を学習するためのiOS向けモバイルゲーム。

## 2. ターゲットユーザー
- 建設業界の従事者（新人・ベテラン問わず）
- DIY愛好家
- 建設について学ぶ学生

## 3. コア機能
### 3.1 学習モード (Learning Mode)
- 工具の画像を表示。
- 正式名称と通称（現場用語）を併記して解説。

### 3.2 スコアアタックモード (Score Attack Mode)
- 制限時間内に工具名を答えるクイズ形式。
- ハイスコア機能で繰り返し学習を促進。

## 4. プラットフォーム
- iOS (Webアプリとして開発し、モバイルブラウザまたはPWAとして動作)

## 5. 必要なアセット
- 建設工具の画像データ
- 名称データベース（正式名称、通称、カテゴリ）
