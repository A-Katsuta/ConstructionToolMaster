# 建設工具マスター - ウォークスルー

## 概要
このドキュメントでは、「建設工具マスター」ゲームの実行方法とテスト手順について説明します。

## 前提条件
- Node.js がインストールされていること。
- 依存関係がインストールされていること（`npm install` 実行済み）。

## 実行方法
1.  ターミナルで `c:/Games/Antigravity/ConstructionToolMaster` を開きます。
2.  開発サーバーを起動します:
    ```bash
    npm run dev
    ```
3.  ターミナルに表示されたURL（通常は `http://localhost:5173`）をブラウザで開きます。

## テスト項目
### 1. タイトル画面
- タイトル「建設工具マスター」が表示されていることを確認します。
- 「学習モード」と「スコアアタック」ボタンがあることを確認します。

### 2. 学習モード (Learning Mode)
- 「学習モード」をクリックします。
- 工具の画像と選択肢が表示されることを確認します。
- 回答を選択します。
- （現状のMVPでは正誤表示のモーダルはなく、すぐに次の問題に進みますが、スコアが加算されていることを確認してください）

### 3. スコアアタック (Score Attack)
- 「スコアアタック」をクリックします。
- タイマーが60秒からカウントダウンすることを確認します。
- 素早く回答していきます。
- 時間切れでゲームが終了することを確認します。

### 4. リザルト画面
- 5問終了（学習モード）または時間切れ（スコアアタック）で、リザルト画面が表示されます。
- 最終スコアと履歴リストが表示されていることを確認します。
- 「タイトルに戻る」をクリックして再スタートできることを確認します。

## 本番用ビルド
本番環境用のファイルを生成するには、以下のコマンドを実行します:
```bash
npm run build
```
生成されたファイルは `dist` フォルダに出力されます。
